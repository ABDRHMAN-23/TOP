# QUVOTO Brand Guide

## Identity
- Brand: QUVOTO
- Tagline: Speak. Quote. Done.
- Primary use: white-first SaaS interface
- Design direction: premium, precise, calm, business-focused

## Colors
- Primary Blue: #1769E0
- Bright Blue: #2F8CFF
- Deep Navy: #0A1E3D
- White: #FFFFFF

## Logo system
- Primary horizontal lockup: symbol + QUVOTO + tagline
- Wordmark lockup: symbol + QUVOTO
- Stacked lockup: symbol / QUVOTO / tagline
- Symbol-only: favicon, app icon, compact navigation
- Dark-background version: reserved for supporting areas
- Avoid heavy gradients, generic AI imagery, robot/brain/microchip symbols, and black-heavy layouts.

## Product distribution
Header: symbol + QUVOTO
Compact header/sidebar: symbol only
Landing hero: primary identity + concise tagline
Login: centered symbol + QUVOTO + tagline
Dashboard: compact QUVOTO identity
Quotation PDF: symbol + wordmark in header
Loading: symbol-first presentation
Mobile app icon: symbol only
Footer: QUVOTO + tagline

## Visual language
Use generous whitespace, rounded but precise cards, navy typography, blue accent states, restrained shadows, and subtle waveform/quotation/completion motifs.
